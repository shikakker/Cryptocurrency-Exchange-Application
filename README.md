# Cryptocurrency Exchange Application

Front-end prototype for comparing cryptocurrency exchange paths and simulating an exchange workflow.

[Live demo](http://crypto.whoisegor.ru/)

## Features

- Login-oriented entry flow.
- Cryptocurrency market-price list.
- Exchange calculator and result view.
- Comparison of alternative exchange paths.
- Transaction-history panel.
- Client-side state management for authentication and exchange selection.

## Tech stack

- React 18 and TypeScript
- Vite
- React Router
- Zustand
- Axios
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start Vite.
- `npm run build` — create a production build.
- `npm run lint` — run ESLint.
- `npm run preview` — preview the build.
